# Part A: Practical Exercises

## Exercise 1 — Command design fundamentals through principle foundations (hierarchy
**Scenario:** provide a realistic Creative Writing & Visual Rhetoric scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** command design fundamentals through principle foundations (hierarchy, alignment grids, contrast systems, proximity grouping, white space), typography systems (association literacy, readability mechanics, hierarchy craft, pairing discipline, brand identity), layout practice (grid application, format conventions, responsive awareness, density judgment), integration craft (copy-space collaboration, caption systems, CTA design, element balance), evaluation practice (critique vocabulary, brief craft, quality checklists, convention awareness), and tool literacy (accessible tools, professional workflow, asset management), avoiding hierarchy flattening, readability sacrifice, white-space fear, taste-only critique, copy throwing, and template fossils failures.
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.

## Exercise 2 — Integrated capstone
**Scenario:** one realistic problem spanning the whole section.
**Objective:** take the problem through every unit's framework in sequence.
**Constraints:** all unit artifacts required and internally consistent; evidence discipline maintained throughout.
**Deliverable:** a coherent campaign/portfolio document assembled as real professional documentation.
**Evaluation criteria:** consistency across artifacts; each capability demonstrably exercised; trade-offs stated at each decision point.
